# ダーツ × ローグライク 戦闘プロトタイプ

## 起動
1. Unityで `Assets/Mock/Scenes/MockBattle.unity` を開く。
2. Playを押す。Gameビューは16:10または16:9、1280px以上の横幅を推奨。
3. メニュー `Mock > Open Battle Prototype` からも開けます。

既存シーンに自動で追加する処理はありません。UIはPlay開始時にMockBattleオブジェクトの子として生成します。

## 線をつなぐ試作（MockBattle2）
- `Assets/Mock/Scenes/MockBattle2.unity` を開いてPlayします。メニュー `Mock > Open Line Battle Prototype` からも開けます。
- 1投目は起点だけを置き、2投目で線1、3投目で線2を作ります。
- 線が横切った内側シングル・トリプル・外側シングル・ダブルの各マスを、1ターン中に1回ずつ発動します。
- 通常盤面は約60%が空マスです。効果マスを多く拾える線を探すこと自体を狙いにしています。
- 線1はカード効果x1、線2はカード効果x2。各線には追加の線ダメージもあります。
- 赤い罠マスを線が通ると7ダメージ。得点だけでなく、安全な経路とカードの並びも狙います。
- 得点目標と3本のダーツ固有効果は残しているため、点数・着弾点・線の経路を同時に考える試作です。
- ターン終了時に線と起点を消し、線で使ったマスだけ再抽選します。敵の罠マスは少しずつ増えます。
- `Mock > Run Line Battle Checks` で専用の戦闘チェックを再実行できます。

## 3段階照準の試作（MockBattle3）
- `Assets/Mock/Scenes/MockBattle3.unity` を開いてPlayします。メニュー `Mock > Open Three Stage Aim Prototype` からも開けます。
- 1回目の左クリックで、盤面半径の半分ほどある青い範囲を固定します。
- 2回目の左クリックで、青い範囲内を揺れる白い中心点を固定します。
- 3回目の左クリックで、中心点から縮小・拡大する金色の着弾範囲を固定して投げます。
- 1ターン目の中心点は一定速度の円運動です。最初の敵ターンで震えが付与され、2ターン目から細かな乱れが加わります。
- `Esc`で操作途中の1投を最初からやり直せます。戦闘・盤面・ダーツの効果はMockBattle1と同じです。
- `Mock > Run Three Stage Aim Checks` で3段階の遷移と中心固定を確認できます。

## 操作
- ダーツのボタン、または **1 / 2 / 3** で未使用ダーツを選択。
- 盤面を **マウス左ボタンで押し続け**、照準円が小さいときに **離して投げる**。
- 照準円内で着弾位置を抽選します。円は旧版より大きく、半径は通常約12〜85px（540pxの盤面）。小さい円ほど高精度で、盤外着弾も1本消費。
- **Esc** で照準をキャンセル。ウィンドウのフォーカスが外れた場合もキャンセル。
- 1ターン各ダーツ1回、合計3本。順番は自由。
- **ターン終了 / Space** で敵の予告行動を順番に解決。残りのダーツは放棄します。
- **再戦** で同じ初期乱数の戦闘を再開始し、攻略方法を比較できます。
- 盤面にマウスを重ねると、右側にカード効果・倍率・危険効果を表示します。盤面左の凡例は各マスの文字を示します。

## 戦闘ルール
- プレイヤーHP70、敵HP135。攻撃は長引くほど強くなります。
- 各扇形は内側シングル・トリプル・外側シングル・ダブルの4マスに分かれ、それぞれ独立してカードを持ちます。暗色は空マスです。
- 外側の細いリングはスコアx2、中間の細いリングはスコアx3。
- 外ブル25点・カードx1、内ブル50点・カードx2。ブルにも通常カードがあります。
- 数字は累計スコアとターン中の目標点に加算。点数そのものは直接ダメージへ変換しません。
- 攻撃：8ダメージ / 防御：7ブロック / 回復：5回復。
- 毒：毒3 / 吸収：4ダメージ＋4回復 / コイン：5コイン。
- 内側・外側シングルは着弾した1マスのカードがx1で発動。ダブルは着弾した1マスのカードがx2で発動します。
- トリプルは着弾した扇形に加え、左右に隣接する扇形のトリプルマスのカードもそれぞれx1で発動します。スコアは着弾した番号のx3です。
- ブルは従来どおり1枚のカードを持ち、外ブルx1・内ブルx2で発動します。回復は最大HPまで。
- 牙のダーツ：命中時に追加3ダメージ。
- 守りのダーツ：命中時に追加4ブロック。
- 毒のダーツ：命中時に追加毒2。
- ダーツ固有効果は倍率対象外。ミスでは発動しません。
- 毒は敵フェーズ開始時にダメージを与え、強度が1減少します。
- ブロックは罠・敵の攻撃を防ぎ、敵フェーズ終了時に残りが消えます。
- 敵は右上の複数行動を表示順に実行。罠を置く番号も予告します。
- 焦り：照準円の伸縮が速くなる / 震え：細かな揺れと散布増加 / 酔い：ゆっくり照準が流れる。
- 状態異常は2ターン。数字は残りターンです。

### ターン目標
- 毎ターン、61・81・101・121・141点のいずれかを抽選し、強い報酬も抽選します。
- そのターンに投げた最大3本の合計点が目標点にちょうど一致した瞬間、報酬が1回発動します。
- 大攻撃：敵に45ダメージ。大回復：HPを最大25回復。鉄壁：防御35を獲得し、焦り・震え・酔いを解除。
- 目標点と報酬、現在の合計点と残り点は右側の目標パネルに常時表示します。
- 超過しても、その投擲で発動したカード・ダーツ効果は有効。目標ボーナスだけ不発になります。
- ターン終了後、目標点と報酬を再抽選し、ターン中の合計点を0へ戻します。累計スコアは残ります。

### 一投の処理順
着弾 → スコア加算 → 発動対象マスのカード（トリプルは左・中央・右） → ダーツ固有効果 → 対象扇形の罠 → 目標達成判定・報酬 → 勝敗判定 → 戦闘続行時のみ発動対象マスを再抽選。

同時に双方のHPが0になった場合は、試作ルールとして敗北を優先します。

### 危険マス
- 地雷：9ダメージ。踏むまで無期限、1回で消滅。
- 炎：5ダメージ。2ターン有効、期間内は何度でも発動。
- 呪い：4ダメージ。戦闘中は何度でも発動し、消滅しない。
- 罠は扇形に残るため、カードが再抽選されても引き継がれます。トリプルでは左右の扇形の罠も発動します。
- 空マスでもスコアは入りますが、カード効果は発動しません。
- コインは開始時のみ出現し、再抽選では空マスまたは通常カードに戻ります。

## 構成・調整
- `Runtime/BattleModel.cs`：UI非依存の戦闘モデル、判定、カード数値、敵予告。
- `Runtime/MockBattle.cs`：uGUI/TMP画面、Input System入力、照準の動き。
- `Runtime/DartBoardGraphic.cs`：メッシュで描く盤面・倍率リング・照準。
- `Editor/MockSetup.cs`：シーン生成、45項目の戦闘チェック。
- `Editor/MockInteractionChecks.cs`：Play Mode上の6項目の操作イベント確認。
- `TextResources/`：Unity付属TMP Essentialsのフォント・シェーダー・ライセンス。
- `Art/MockUI.shader`：Mock専用のフラットUI描画。
- `Scenes/MockBattle.unity`：実行用シーン。

戦闘チェックは `Mock > Run Combat Checks` で再実行できます。
操作イベント確認はPlay Mode中に `DartsRoguelike.Mock.Editor.MockInteractionChecks.Run()` を実行します。

## 範囲
Unity 6000.5.9f1、導入済みのuGUI/TMPとInput Systemを使用。
UIは日本語表記。日本語フォントはMock内のNoto Sans CJK JP（SIL Open Font License）を使用。報酬選択、ショップ、デッキ編集、複数戦のラン、音声はこの戦闘試作の対象外です。
ゲーム内容の追加ファイルはAssets/Mockに格納しています。
Unityがフォルダ識別用に生成する `Assets/Mock.meta` は、Mockフォルダの隣に置かれます。
Package/ProjectSettingsや既存シーンを保存・編集するセットアップ処理はありません。

## 日本語フォント
`Art/Fonts/MockJapanese.asset` に使用文字を静的に焼き込んでいます。フォント・素材・ライセンスはMock内に格納されています。
出典：Noto CJK公式リポジトリ https://github.com/notofonts/noto-cjk
日本語テキストを増やす際は新しい文字がフォントに含まれるか確認してください。
