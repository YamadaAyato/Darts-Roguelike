# ダーツ × ローグライク 戦闘プロトタイプ

## 起動
1. Unityで `Assets/Mock/Scenes/MockBattle.unity` を開く。
2. Playを押す。Gameビューは16:10または16:9、1280px以上の横幅を推奨。
3. メニュー `Mock > Open Battle Prototype` からも開けます。

既存シーンに自動で追加する処理はありません。UIはPlay開始時にMockBattleオブジェクトの子として生成します。

## 操作
- ダーツのボタン、または **1 / 2 / 3** で未使用ダーツを選択。
- 盤面を **マウス左ボタンで押し続け**、照準円が小さいときに **離して投げる**。
- 照準円内で着弾位置を抽選します。小さい円ほど高精度。盤外着弾も1本消費。
- **Esc** で照準をキャンセル。ウィンドウのフォーカスが外れた場合もキャンセル。
- 1ターン各ダーツ1回、合計3本。順番は自由。
- **END TURN / Space** で敵の予告行動を順番に解決。残りのダーツは放棄します。
- **RESTART** で同じ初期乱数の戦闘を再開始し、攻略方法を比較できます。
- 盤面にマウスを重ねると、右側にカード効果・倍率・危険効果を表示します。

## 戦闘ルール
- プレイヤーHP70、敵HP135。攻撃は長引くほど強くなります。
- 外側の細いリングはx2、中間の細いリングはx3。
- 外ブル25点・カードx1、内ブル50点・カードx2。ブルにも通常カードがあります。
- 数字はスコアに加算。今回はスコアを直接ダメージへ変換しません。
- STRIKE：8ダメージ / GUARD：7ブロック / HEAL：5回復。
- POISON：毒3 / DRAIN：4ダメージ＋4回復 / COIN：5コイン。
- カード数値に盤面倍率を適用。回復は最大HPまで。
- FANG：命中時に追加3ダメージ。
- AEGIS：命中時に追加4ブロック。
- VENOM：命中時に追加毒2。
- ダーツ固有効果は倍率対象外。ミスでは発動しません。
- 毒は敵フェーズ開始時にダメージを与え、強度が1減少します。
- ブロックは罠・敵の攻撃を防ぎ、敵フェーズ終了時に残りが消えます。
- 敵は右上の複数行動を表示順に実行。罠を置く番号も予告します。
- PANIC：照準円の伸縮が速くなる / TREMOR：細かな揺れと散布増加 / DRUNK：ゆっくり照準が流れる。
- 状態異常は2ターン。数字は残りターンです。

### 一投の処理順
着弾 → スコア加算 → カード → ダーツ固有効果 → 罠 → 勝敗判定 → 戦闘続行時のみ使用したカードを再抽選。

同時に双方のHPが0になった場合は、試作ルールとして敗北を優先します。

### 危険マス
- MINE：9ダメージ。踏むまで無期限、1回で消滅。
- FIRE：5ダメージ。2ターン有効、期間内は何度でも発動。
- CURSE：4ダメージ。戦闘中は何度でも発動し、消滅しない。
- 罠は扇形に残るため、カードが再抽選されても引き継がれます。
- コインは開始時のみ出現し、再抽選では通常カードに戻ります。

## 構成・調整
- `Runtime/BattleModel.cs`：UI非依存の戦闘モデル、判定、カード数値、敵予告。
- `Runtime/MockBattle.cs`：uGUI/TMP画面、Input System入力、照準の動き。
- `Runtime/DartBoardGraphic.cs`：メッシュで描く盤面・倍率リング・照準。
- `Editor/MockSetup.cs`：シーン生成、26項目の戦闘チェック。
- `Editor/MockInteractionChecks.cs`：Play Mode上の6項目の操作イベント確認。
- `TextResources/`：Unity付属TMP Essentialsのフォント・シェーダー・ライセンス。
- `Art/MockUI.shader`：Mock専用のフラットUI描画。
- `Scenes/MockBattle.unity`：実行用シーン。

戦闘チェックは `Mock > Run Combat Checks` で再実行できます。
操作イベント確認はPlay Mode中に `DartsRoguelike.Mock.Editor.MockInteractionChecks.Run()` を実行します。

## 範囲
Unity 6000.5.9f1、導入済みのuGUI/TMPとInput Systemを使用。
UIは英語表記。報酬選択、ショップ、デッキ編集、複数戦のラン、音声はこの戦闘試作の対象外です。
ゲーム内容の追加ファイルはAssets/Mockに格納しています。
Unityがフォルダ識別用に生成する `Assets/Mock.meta` は、Mockフォルダの隣に置かれます。
Package/ProjectSettingsや既存シーンを保存・編集するセットアップ処理はありません。
